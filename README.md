# 🔐 Password Manager

A Python-based password manager project focused on secure credential handling and authentication workflows.

## 🚀 Features

- Secure credential storage
- OTP-based authentication system
- Hashing and basic security workflows
- Simple authentication/login functionality

## 🛠️ Technologies Used

- Python
- cryptography
- pyotp

## 📚 Purpose

This project was created for learning and experimenting with authentication systems, credential security concepts, and cybersecurity-oriented Python development.

## ⚠️ Setup

Create a `.env` file and configure the required environment variables before running the project.

## 🚧 Status

Learning project built for experimentation and educational purposes.
